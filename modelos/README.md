# Vitrine de modelos de sites — VOLTTA System

Demonstrações navegáveis, para apresentação comercial de seis formatos: site institucional, loja virtual, landing page, portfólio, catálogo online e cardápio digital.

## Acessos
- Hub: `/modelos/`
- Institucional: `/modelos/institucional/`
- Loja virtual: `/modelos/loja-virtual/`
- Landing page: `/modelos/landing-page/`
- Portfólio: `/modelos/portfolio/`
- Catálogo: `/modelos/catalogo-online/`
- Cardápio digital: `/modelos/cardapio-digital/`

## Experiências demonstrativas
- Site institucional: projetos, apresentação e formulário com confirmação local.
- Loja virtual: categorias, busca, carrinho e checkout apenas simulado.
- Landing page: proposta de valor, benefícios e captura de contato simulada.
- Portfólio: galeria filtrável e ampliação de imagens.
- Catálogo online: categorias, busca e consulta sem transação.
- Cardápio: adicionais pagos, carrinho e simulação de pedido.
- Vitrine: reunião dos seis exemplos, com link comercial para a VOLTTA.

**Atenção:** empresas, marcas e dados usados aqui são fictícios; imagens externas do Unsplash são ilustrativas. Os formulários não enviam dados. As interações de carrinho funcionam no navegador; não há pedidos, pagamento, admin, estoque ou banco de dados. Não apresentar esses protótipos como operações reais.

## Executar
Na raiz de `voltta-system-site`: `python3 -m http.server 8000`. Abra `http://localhost:8000/modelos/`.

## Publicação
Compatível com hospedagem estática no GitHub Pages sob a pasta `/voltta-system-site/modelos/`, caso o Pages da branch raiz já esteja configurado. Confirme a implantação no painel da hospedagem. Evite deploy separado por segmento inicialmente, para reduzir a manutenção.

## Evoluir para um projeto de cliente
Cada protótipo precisa de identidade real, fotos licenciadas, textos aprovados, integrações específicas, política de privacidade/LGPD aplicável, preços e condições comerciais reais. Loja e cardápio necessitam backend seguro, validação no servidor, painel e fluxo de pagamento ou pedidos antes de operar comercialmente.

Projeto desenvolvido como demonstração de portfólio VOLTTA System.
